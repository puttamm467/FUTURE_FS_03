# 🌸 QuickFix – Home Services Website

A modern, responsive home services website designed to make booking everyday household services simple, convenient, and accessible.

## 📌 Project Overview

QuickFix is a frontend web development project created as part of my **Future Interns Internship – Task 1**.

The website provides customers with a simple platform to explore home services, view starting prices, and submit service booking enquiries through WhatsApp.

## 🎯 Problem Statement

Finding reliable home service professionals and contacting them quickly can be challenging.

QuickFix addresses this problem by providing a centralized website where customers can:

- Explore different home services.
- View service information and starting prices.
- Submit booking enquiries.
- Contact the business through WhatsApp.

## ✨ Features

- Beautiful pink-themed user interface.
- Responsive design for desktop and mobile devices.
- Home, Services, About, and Contact sections.
- Service cards with descriptions and starting prices.
- Interactive booking enquiry form.
- Customer input validation.
- WhatsApp enquiry integration.
- Smooth scrolling and hover effects.
